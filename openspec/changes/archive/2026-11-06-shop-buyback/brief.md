## Wish

"Beim Villager, für die Migration erstmal default deaktiviert, dass der auch Sachen zurückkauft. Wenn ich einen Villager erstelle, der Diamantblöcke für 900 Bits verkauft, dann kann man auch mit dem Diamantblock hingehen und kriegt 900 Bits."

## Decisions

| # | Question | Answer | Source |
| --- | --- | --- | --- |
| Q1 | Where is buyback switched on? | Per offer, off by default, so existing shops do not change | user |
| Q2 | What does the shop pay? | Its own buyback price per offer, preset to the sale price when switched on, changeable by the team | user |
| Q3 | Who pays? | The owning team's account; the goods go into the stock chest; no new bits are created | user |
| Q4 | What if the team cannot pay or the chest is full? | The shop refuses with a clear message and nothing changes hands | user |
| Q5 | May members of the owning team sell to their own shop? | Yes, like everyone else. Accepted risk: a single member can drain the team account by raising the price | user |
| Q6 | Does the marketplace show buyback? | Yes, in this change | user |
| Q7 | How is selling triggered? | Right click on an offer, one lot per click; left click stays buying, because it already buys | delegated |
| Q8 | Which goods count? | Only items identical to the offer's item, in the offer's lot size, the same match the stock uses | delegated |
| Q9 | What if the launcher answers too late? | A debit carries a deadline and the launcher drops it once expired, so a late launcher moves no bits | user |

## Out of scope

- Buy-only offers: buyback is an option of an existing offer.
- NPC buyers that create new bits.
